# Mitmachen

Danke, dass du VD-Link besser machen willst!

- **Fehler und Wünsche:** als Issue (Vorlagen „Fehler melden“ und „Fixture fehlt oder falsch“).
- **Code:** Node.js 22, `npm install`, `npm run fixtures` (einmalig), `npm run dev`. Vor einem Pull Request `npm run check`.
- **Lizenzen:** Nur Bausteine mit freizügiger Lizenz (MIT, Apache-2.0, BSD, ISC, SIL OFL für Schriften, CC0 für Grafiken).
  Neue Abhängigkeiten bitte in `THIRD_PARTY.md` eintragen. Keine Inhalte aus proprietären Bibliotheken (MA, Daslight, Capture, GDTF-Share-Massendownloads).
- **Herkunft:** Für auffällige Algorithmen, Shader oder Protokoll-Konstanten die Herkunft prüfen und nur mit passender Lizenz und Nennung übernehmen.

Mit einem Beitrag stimmst du zu, dass er unter der Eclipse Public License 2.0 steht.
