# Logo-Entwürfe VD-Link

Vier Entwürfe im Stil der Suite (dunkle Kachel, Inter Display ExtraBold, fünf Suite-Farben):
1. Lichtrampe · 2. **Bühnenboden (gewählt, 13.11.2026)** · 3. Iso-Blöcke · 4. Sucher

`vergleich.png` zeigt alle vier. Neu zeichnen: `npx electron docs/logo-entwuerfe/entwuerfe.cjs <Zielordner>`.
Das gewählte Logo wird mit `npm run logo` (scripts/logo/render.cjs) erzeugt; im Programm zeichnet `logoSlots()` in src/ui/dom.ts dieselbe Form als SVG.
Idee für LJ-Link später: dasselbe System, eigenes Zeichen (z. B. Entwurf 3 „Iso-Blöcke“ als 3D-Variante der LJ-Balken).
