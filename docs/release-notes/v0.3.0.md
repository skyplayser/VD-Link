**Ab jetzt installierst und aktualisierst du VD-Link am einfachsten mit Link-Suite: https://skyplayser.github.io/Link-Suite/**

## Neu in 0.3.0

- **Startanimation der Link-Suite:** Beim Programmstart fächern alle Programme der Suite aus dem Suite-Zeichen auf, VD-Link fliegt auf sein Logo im Startbildschirm, die Kacheln blenden ein (höchstens 2,5 s). Überspringen mit jeder Taste oder Klick, „Bewegung reduzieren“ wird beachtet. Einmal je Start, nicht nach einem Absturz. Abschaltbar unter Einstellungen → Oberfläche → Startanimation (Wie die Suite / An / Aus).
- **Karte „Link-Suite laden“:** Ist der Launcher Link-Suite nicht installiert, zeigt der Startbildschirm rechts eine kleine Karte dazu. Die Prüfung läuft nur lokal auf deinem Rechner; ins Netz geht erst der Klick auf „Link-Suite laden“. „Nicht mehr zeigen“ blendet sie dauerhaft aus.

**From now on, the easiest way to install and update VD-Link is Link-Suite: https://skyplayser.github.io/Link-Suite/**

## New in 0.3.0

- **Link-Suite start animation:** When the program starts, all suite programs fan out of the suite symbol, VD-Link flies onto its logo on the start screen and the tiles fade in (2.5 s at most). Skip with any key or a click; “Reduce motion” is respected. Once per start, not after a crash. Can be turned off under Settings → Interface → Start animation (Like the suite / On / Off).
- **“Get Link-Suite” card:** If the Link-Suite launcher is not installed, the start screen shows a small card about it on the right. The check runs locally on your computer only; nothing goes online until you click “Get Link-Suite”. “Don’t show again” hides it for good.

## Install individually

The installers are still below under **Assets**: `VD-Link-macos-arm64.dmg` (Mac with Apple chip), `VD-Link-macos-x64.dmg` (Mac with Intel), `VD-Link-windows.exe` (Windows 10/11). The app is not signed yet – first-start notes: [Installation](https://github.com/skyplayser/VD-Link/blob/main/docs/INSTALLATION.md).
